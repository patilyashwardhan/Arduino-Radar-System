-Project Overview:
	The Arduino Radar System is a mini radar simulation project built using Arduino and ultrasonic sensor technology.
It detects nearby objects and displays their position in real-time using a radar-style visualization on a computer screen.

This project demonstrates the working principle of real radar systems using affordable electronic components.

-Components Used:
	Arduino Board.
	Ultrasonic Sensor (HC-SR04).
	Servo Motor.
	Buzzer.
	Jumper Wires.
	Breadboard.

-Working Principle:
	The servo motor rotates from 0° to 180°.

	The ultrasonic sensor measures the distance of objects.

	Distance data is sent to the computer via Serial communication.

-Circuit Connections:
	
	.Ultrasonic sensor

	VCC	5V
	GND	GND
	Trig	Digital Pin 
	Echo	Digital Pin 

	.Servo Motor

	VCC	5V
	GND	GND
	Signal	Digital Pin (PWM PIN)

-Software Used:
	Arduino IDE.
